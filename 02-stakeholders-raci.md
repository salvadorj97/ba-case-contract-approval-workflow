# 2. Stakeholders and RACI

## Stakeholders

| Stakeholder | Interest | Influence |
|---|---|---|
| Regional Director | Faster contract signature, regional performance | High |
| Headquarters decision-makers | Only high-risk contracts reach them, with clear context | High |
| Contract and Commercial Fulfilment Managers (CCFM) | Reviews that move without manual chasing | High |
| Sales | Fast answer for customers and tenders | Medium |
| Country reviewers (Product, Service, Channel, Finance, Supply Chain, Commercial) | Clear requests, only the part of the contract that concerns them | Medium |
| Regional reviewers | Enough context to decide on medium-risk contracts | Medium |
| IT and Process Analysts | Feasible changes in the in-house platform | Medium |

## RACI for the improvement project

R = Responsible, A = Accountable, C = Consulted, I = Informed

| Activity | Product Owner | Scrum Master | CCFM | IT and Process Analysts | Country reviewers | Regional Director |
|---|---|---|---|---|---|---|
| Prioritise the backlog | A, R | C | C | C | I | I |
| Build the Risk Table into the platform | A | I | C | R | C | I |
| Automate reminders and backup | A | I | C | R | C | I |
| Make reasons mandatory on votes | A | I | C | R | C | I |
| Define prioritisation criteria | A | C | R | C | C | C |
| Train teams on the Risk Table | A | R | R | I | C | I |
| Test the new workflow | A | C | C | C | R | I |
| Run sprint ceremonies | C | A, R | C | C | C | I |

In the original plan, the Product Owner and the Scrum Master were both regional managers who already handled country workflows, chosen because they knew the process and could dedicate time to it.
